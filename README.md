# بريد الجمعة — Android App

Wrapper app for https://abdelwahabmetawe.blogspot.com/ — opens the blog
fullscreen, keeps blog pages inside, opens YouTube/store links outside,
pull-to-refresh, back button walks WebView history.

## Get the APK (free, no Android Studio, ~10 MB download)

1. Create an empty public GitHub repo (e.g. `fridaymail-app`), upload this
   folder's contents to `main`.
2. Open the repo's **Actions** tab → **Build APK** → download the
   `fridaymail-apk` artifact → inside is `app-debug.apk`.
3. Send the APK to any Android phone, tap to install (allow
   "install unknown apps" once). Future updates = push + download again.
